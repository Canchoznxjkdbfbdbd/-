# НутриКод

Анонимный веб-чат с ИИ-нутрициологом. Без регистрации и без сбора имени. Русский интерфейс.

## Стек

- Node.js + Express
- Vanilla HTML / CSS / JS
- Google Gemini (SSE streaming); без ключа — демо-стрим для превью UI

## Быстрый старт

```bash
npm install
cp .env.example .env
# при желании: впишите GEMINI_API_KEY в .env
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

Без `GEMINI_API_KEY` чат отвечает mock-стримом — удобно смотреть дизайн.

### Обновить уже скачанную копию

В папке проекта (например `C:\Users\alexandr\nutrikod`):

```bash
git pull
npm install
npm start
```

Если в `.env` указано старое имя модели (`gemini-2.0-flash`), замените на `gemini-3.8-flash` или удалите строку `GEMINI_MODEL` — подставится актуальная по умолчанию.

Если ответы обрывались на полуслове, убедитесь что нет `GEMINI_MAX_OUTPUT_TOKENS=1024` (или поставьте `8192`). Ключ `GEMINI_API_KEY` менять не нужно.

## Переменные окружения

| Переменная                 | Описание                                      |
|----------------------------|-----------------------------------------------|
| `GEMINI_API_KEY`           | ключ Gemini (опционально для демо)            |
| `GEMINI_MODEL`             | по умолчанию `gemini-3.8-flash`               |
| `GEMINI_MAX_OUTPUT_TOKENS` | длина ответа, по умолчанию `8192`             |
| `PORT`                     | порт, по умолчанию `3000`                     |
| `DONATE_URL`               | ссылка на оплату доната (заглушка `#donate`)  |

## Поведение

- Приветствие и первый вопрос о рационе / аллергиях / цели
- Стриминг ответа (SSE)
- Мягкая партнёрская подсказка не чаще одного раза и только при подходящем намерении
- Анонимные 👍/👎 в `localStorage`
- Тихая полоска доната под чатом после 3 сообщений (100 / 300 / 500 ₽)
- Юридический дисклеймер в подвале
